# ease-stock
> A lightweight, easy to use Inventory Management System (IMS) designed for speed, simplicity and efficiency 

## Overview:
ease-stock was initially developed as a school project but quickly scaled into a real-world solution to handle stock tracking for my family business. It has a minimalist design  with a  fast, terminal-driven interface that solves genuine business bottlenecks which prioritizes function over form.

##  Specifications:
*   **Language:** Python 3.13
*   **Database:** MySQL

## Key Features:
*   **Streamlined UI:** A clean, easy-to-use menu system with a minimal learning curve.
*   **Core Stock Management:** Efficient addition, modification, and withdrawal of inventory items.
